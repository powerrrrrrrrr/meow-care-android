# Meow Care Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development to implement and review task-by-task. Do not commit or publish. The user authorized continuous implementation after accepting the product design.

**Goal:** Deliver a Java Android personal cat-cleaning tracker with durable records, calendar, editable tasks and local daily reminders.
**Architecture:** Java/XML UI delegates to a SQLite repository. A pure Java domain layer owns date rules; a receiver and scheduler own notifications.
**Tech Stack:** Java 17, Android SDK 35/min26, AGP 8.7.3, Gradle 8.9, AppCompat 1.7.0, Material 1.12.0.
**Spec:** docs/superpowers/specs/2026-09-06-meow-care.md

## Global Constraints
- Java application source only; XML layouts. minSdk 26, compileSdk 35, targetSdk 35.
- package/namespace `com.meowcare.app`; app name 喵洁日历.
- Offline personal app; no INTERNET permission, no fake completion history.
- Interval 1–365 calendar days. Future record timestamps rejected.
- Completion history is source of truth; latest = maximum completed_at.
- No git commits, publishing, or changes outside this project without controller authorization.
