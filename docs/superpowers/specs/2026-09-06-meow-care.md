# 喵洁日历 v0.1 需求与架构

## 决策依据
用户已认可 HTML 产品介绍，要求 Java，并授权需求拆解、架构设计与代码开发。以认可方案为产品基线，在当前会话连续实现。名称暂定；本地个人版，中文界面。新目录隔离，不修改其他项目。

## 产品边界
目标：用户能回答每项清洁上次何时完成、今天是否到期，并快速留下可修正的真实记录。
包含：今天、月历、设置三个页面；五项初始任务（铲猫砂、整盆更换猫砂、清洗猫砂盆、清洗饮水盆、清洗饭盆）；增加、编辑、停用任务；完成、补记、编辑和删除记录；本地提醒。
不包含：账号、联网、家庭共享、付费、宠物健康诊断、云同步。用户数据不自动填充虚假完成历史。预置任务不等同于兽医护理建议。

## 用户故事与验收
1. 首次打开看到五项未记录任务，明确显示“还没有记录”，不把安装日伪装为完成日。
2. 任务展示物品位置/名称、最后一次日期、距今天数、到期状态；未记录排前，其次逾期、今日到期、正常。一个物品可有不同任务，同一类型可添加多个物品。
3. 点“完成”保存当前真实时间，首页与月历立即刷新。撤销只移除本次创建的记录。重复点按不会意外插入重复事件（按钮提交中禁用）。
4. 可为选中日期补记，并选择具体时间；禁止未来完成时间。编辑、删除记录后以剩余记录中的最大完成时间重新计算上次完成。删除有确认。补记旧日期不覆盖较新的完成时间。
5. 周期整数 1–365 天，支持单项不提醒。间隔按设备当前时区的自然日计算；dueDate = latestCompletionDate.plusDays(intervalDays)。未记录显示待记录，提醒开启且有到期/未记录任务时可计入汇总。历史日期因用户更改系统时区而按新当地日期显示。
6. 月历可切月、选日，标出有记录日期，显示当天清洁历史；空状态清楚，未来日期不允许新增记录。
7. 设置可新增/编辑任务的标题、物品名称、周期、单项提醒及停用。停用隐藏今日任务并停止提醒，历史保留，设置可恢复。
8. 全局提醒默认关闭，用户选择每日时间后开启。Android 13+ 主动请求通知权限，拒绝后不谎称通知已启用。每日非精确汇总通知，点击进入首页；无到期事项不发送。同日不重复通知。重启、时间/时区变更后重排，强行停止与厂家省电限制可能延迟，设置说明清晰。
9. 数据在进程重启后保留；SQLite 操作在单线程执行器；错误反馈到界面，不静默成功。时间和日期计算独立于 Android，可作 JVM 单元测试。
10. UI 沿用蓝色、清爽卡片、今天/月历/设置导航；支持系统深浅色、滚动、大字体、键盘避让与系统栏。按钮可读且有无障碍标签。

## 架构
- Java 17 + XML，minSdk 26、compileSdk 35、targetSdk 35；Gradle 8.9、AGP 8.7.3、AppCompat 1.7.0、Material 1.12.0（已有缓存）。
- 单 Activity 承载三个页面，由各页面控制类负责渲染与交互；不把持久化或通知策略塞入 Activity。
- domain：不可变 Task、CareRecord，纯 Java CareRules 计算日期、状态与校验。
- data：SQLiteOpenHelper + CareRepository。任务表 tasks(id,title,item,interval_days,remind,active)；记录表 records(id,task_id,completed_at)。索引(task_id,completed_at)，外键开启。参数绑定，记录 ID 独立，MAX 而非插入顺序确定上次。
- UI：Activity、TodayController、CalendarController、SettingsController、表单对话框、XML 卡片。执行器处理数据操作，主线程显示状态，关闭页面回调不更新销毁的 Activity。
- reminder：SharedPreferences 保存全局开关/时间/上次通知日期；AlarmManager.setAndAllowWhileIdle 安排下一次汇总，无精确闹钟权限；BroadcastReceiver.goAsync 查询后发 NotificationChannel 通知，处理开机和时间变化。
- SQLite 替代此前讨论的 Room 是当前实现选择：数据模型小，减少编译依赖；Repository 隔离 SQL，后续可迁移。

## 测试与交付
- JVM：自然日跨月/闰年、到期/逾期、未记录、未来时间拒绝、周期边界、补记排序、下一次提醒时间。
- 设备：数据库持久化与记录修正、任务停用与恢复；UI 创建/完成/撤销/补记/月历/周期；通知权限及调度。
- 输出 Android Studio 工程、debug APK、需求/架构、实施计划、验证记录；无真实用户数据预装。debug APK 非商店发布版本。
